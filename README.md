# Test

Testen mit cloud zu programmieren

## Inhalt

- [`index.html`](index.html) — Snake-Spiel zum Spielen
- [`programmieren-lernen.html`](programmieren-lernen.html) — Interaktiver
  Mini-Kurs auf Deutsch: JavaScript-Grundlagen mit Beispielen, die du direkt
  im Browser ausführen und verändern kannst.

## Programmieren lernen

Öffne `programmieren-lernen.html` in einem Browser. Du brauchst nichts zu
installieren — alle Lektionen laufen lokal. Die neun Kapitel:

1. Hallo Welt
2. Variablen
3. Rechnen & Text
4. Bedingungen (`if` / `else`)
5. Schleifen
6. Funktionen
7. Arrays
8. Snake-Spiel verstehen
9. Wie geht es weiter?
