👋 Willkommen — lass uns programmieren lernen

Dieser Kurs ist eine kleine Einführung in JavaScript, die Sprache, in der z. B. dein Snake-Spiel geschrieben ist. Du brauchst nichts zu installieren — alle Beispiele kannst du direkt hier im Browser ausführen und verändern.

1 · Dein erstes Programm: „Hallo Welt“

Mit console.log(...) gibt JavaScript Text aus. Wir leiten die Ausgabe unten in das schwarze Feld um, damit du sie sehen kannst.

💡 Tipp: Probier ruhig herum! Ändere den Text in den Anführungszeichen und drücke wieder „Ausführen“.

2 · Variablen — Werte merken

Eine Variable ist wie eine Schublade mit einem Namen, in der du etwas ablegst. In modernem JavaScript benutzt man dafür let (kann sich ändern) oder const (bleibt konstant).

Aufgabe

Erstelle eine Variable lieblingsfarbe und gib „Meine Lieblingsfarbe ist …“ aus.

3 · Rechnen und Text verknüpfen

JavaScript kann rechnen wie ein Taschenrechner: +, -, *, /. Mit Backticks (`) und ${...} kannst du Werte hübsch in Text einbauen (sogenannte Template-Strings).

4 · Entscheidungen treffen: if / else

Mit if prüft das Programm eine Bedingung. Ist sie true (wahr), läuft der eine Code, sonst der andere. Vergleichsoperatoren: === (gleich), !== (ungleich), <, >, <=, >=.

Aufgabe

Ändere punkte und schaue, welche Note ausgegeben wird.

6 · Funktionen — eigene Befehle bauen

Eine Funktion ist ein wiederverwendbares Stück Code mit Namen. Du steckst etwas rein (Parameter) und bekommst etwas zurück (return).

Aufgabe

Schreib eine Funktion addiere(a, b), die die Summe zurückgibt.

7 · Arrays — Listen von Werten

Ein Array ist eine Liste. Im Snake-Spiel ist die Schlange genau so eine Liste — eine Reihe von Koordinaten!

9 · Wie geht es weiter?

  1. Spiele mit den Beispielen oben — verändere Zahlen, Texte, Bedingungen.
  2. Öffne index.html in einem Editor und versuche, eine Zeile zu ändern (z. B. die Spielfarbe #4ade80).
  3. Lerne als nächstes: Objekte, DOM (Webseite verändern) und Events (auf Klicks reagieren).
  4. Gute kostenlose Quellen: developer.mozilla.org (MDN), javascript.info.
